Catatan Belajar

Bab 4: Operator Perbandingan, Boolean, dan Percabangan

Pada bab sebelumnya, program menerima masukan dan menampilkan hasilnya. Bab ini membahas cara program memeriksa kondisi, lalu memilih tindakan yang sesuai menggunakan operator perbandingan, nilai Boolean, serta percabangan if, elif, dan else.

Banyak cara untuk menuju satu tujuan

Catatan versi. Catatan ini mengacu pada Python 3.14.x. Nama fungsi dan pesan kesalahan pada versi yang lebih baru dapat sedikit berbeda.

Tujuan pembelajaran

Setelah menyelesaikan bab ini, kemampuan berikut dapat dipraktikkan langsung.

  • Memahami operator perbandingan seperti ==, !=, >, dan <=.
  • Memahami tipe data Boolean, yaitu True dan False.
  • Menggabungkan kondisi dengan and, or, dan not.
  • Menulis percabangan if, elif, dan else.
  • Menggabungkan input() dengan kondisi untuk membuat program interaktif.
  • Memahami kesalahan umum dalam penulisan kondisi.
  • Membuat program sederhana yang mampu mengambil keputusan.

1. Apa itu kondisi?

Kondisi adalah pernyataan atau ekspresi yang dipakai untuk memeriksa apakah sesuatu bernilai benar atau salah.

Dalam kehidupan sehari-hari, keputusan seperti ini diambil berkali-kali. Contohnya, ketika keluar rumah.

Jika hujan turun, payung dibawa.

Logika tersebut dapat dituliskan lebih tegas:

Kondisi: Apakah sedang hujan?

Jika YA:
    Bawa payung

Jika TIDAK:
    Tidak perlu membawa payung

Dalam Python, logika itu direpresentasikan oleh variabel Boolean:

hujan = True
if hujan:
    print("Bawa payung")

Hasil:

Bawa payung

Karena variabel hujan bernilai True, perintah di dalam blok tersebut dijalankan.

Kondisi membuat program tidak harus menjalankan seluruh instruksi dengan cara yang sama setiap kali. Program dapat memilih tindakan sesuai dengan data yang diperiksa. Inilah yang disebut alur kendali.

2. Mengapa program membutuhkan kondisi?

Perhatikan program sederhana berikut.

nilai = 80
print(f"Nilai: {nilai}")

Hasil:

Nilai: 80

Program tersebut hanya menampilkan data. Untuk menentukan kelulusan, diperlukan aturan berikut.

  • nilai 60 atau lebih berarti lulus;
  • nilai di bawah 60 berarti belum lulus.

Aturan itu diterjemahkan menjadi kondisi:

nilai = 80
if nilai >= 60:
    print("Lulus")
else:
    print("Belum lulus")

Hasil:

Lulus

Program sekarang tidak sekadar menampilkan data, tetapi mengolahnya menjadi keputusan.

Operator perbandingan membandingkan dua nilai. Hasil perbandingan berupa Boolean, yaitu True atau False.

4. Operator == — sama dengan

Operator == memeriksa apakah dua nilai sama.

print(10 == 10)
print(10 == 5)

Hasil:

True
False

Pada 10 == 10, kedua nilai sama sehingga hasilnya True. Pada 10 == 5, keduanya berbeda sehingga hasilnya False.

Operator ini juga dapat membandingkan dua variabel:

first_value = 20
second_value = 20
print(first_value == second_value)

Hasil:

True

5. Operator != — tidak sama dengan

Operator != memeriksa apakah dua nilai berbeda.

print(10 != 5)
print(10 != 10)

Hasil:

True
False

10 != 5 bernilai True karena kedua angka berbeda. 10 != 10 bernilai False karena keduanya sama.

Contoh penerapan:

password = "python123"
if password != "admin123":
    print("Akses ditolak")

Karena nilai password berbeda dari admin123, kondisi bernilai True dan pesan ditampilkan.

6. Operator > — lebih besar dari

print(10 > 5)
print(5 > 10)

Hasil:

True
False

Contoh penggunaan:

saldo = 50000
print(saldo > 10000)

Hasil:

True

Saldo 50.000 lebih besar daripada 10.000. Perhatikan perbedaan berikut.

print(10 > 10)

Hasilnya False, bukan True, karena operator > tidak memasukkan nilai yang sama.

7. Operator < — lebih kecil dari

print(10 < 5)

Hasil:

False

Contoh penerapan:

Kondisi tersebut dapat dipakai untuk memeriksa apakah stok barang sudah menipis.

8. Operator >= — lebih besar dari atau sama dengan

score = 60

Nilai 60 tetap memenuhi syarat karena batas tersebut termasuk dalam perbandingan.

user_age == 18

11. Apa itu Boolean?

Boolean adalah tipe data yang hanya memiliki dua nilai kebenaran:

True
False

True berarti benar, sedangkan False berarti salah. Python memakai nilai Boolean untuk mewakili hasil kondisi.

is_raining = True
is_hot = False

print(is_raining)
print(is_hot)

Hasil:

True
False

Perhatikan bahwa True dan False tidak memakai tanda kutip. Penulisan berikut berbeda.

is_active = True      # Boolean
is_active = "True"    # string

Nilai pertama bertipe Boolean, sedangkan nilai kedua bertipe string karena ditulis di dalam tanda kutip.

Fungsi type() dapat dipakai untuk memastikan tipenya.

status = True
print(type(status))

Hasil:

<class 'bool'>

bool adalah nama tipe data Boolean dalam Python.

14. Variabel Boolean di dalam kondisi

Variabel Boolean dapat langsung dipakai sebagai kondisi tanpa perbandingan tambahan.

is_logged_in = True
if is_logged_in:
    print("Selamat datang")

Hasil:

Selamat datang

Bentuk ini lebih ringkas daripada menuliskan perbandingan secara langsung.

if is_logged_in == True:
    print("Selamat datang")

Keduanya memberi hasil sama pada contoh tersebut, tetapi bentuk pertama lebih lazim digunakan.

15. Struktur if

Pernyataan if menjalankan suatu blok kode hanya ketika kondisinya bernilai benar.

if kondisi:
    # blok yang berjalan jika kondisi benar

Ada dua bagian penting pada bentuk tersebut.

  • if kondisi: memeriksa apakah kondisi bernilai benar.
  • Baris yang menjorok ke bawah adalah blok yang dijalankan ketika kondisi terpenuhi.

Tanda titik dua menandai awal blok, sedangkan indentasi menentukan baris mana yang termasuk ke dalam blok. Konvensi yang umum adalah empat spasi.

15.1 Contoh paling sederhana

user_age = 20
if user_age >= 18:
    print("Sudah dewasa")

Hasil:

Sudah dewasa

Langkahnya dapat diuraikan sebagai berikut.

Pertama, variabel user_age bernilai 20.

user_age = 20

Kedua, Python memeriksa kondisi.

user_age >= 18

Secara logika:

20 >= 18
   ↓
True

Ketiga, karena kondisi bernilai True, Python menjalankan print("Sudah dewasa"). Jika nilai user_age diganti menjadi 15, kondisi bernilai False sehingga baris tersebut dilewati.

15.2 Contoh ketika kondisi bernilai salah

user_age = 15
if user_age >= 18:
    print("Sudah dewasa")
print("Program selesai")

Hasil:

Program selesai

Pesan pertama tidak muncul karena kondisi berikut menghasilkan False.

15 >= 18

Python melewati blok if lalu melanjutkan ke baris berikutnya yang berada di luar blok tersebut. Inilah prinsip dasar if: blok hanya berjalan ketika kondisinya benar.

16. Memahami indentasi

Indentasi adalah jarak ke awal baris kode. Dalam Python, indentasi bukan sekadar tampilan, melainkan bagian dari aturan sintaks. Tanpa indentasi, Python tidak dapat menentukan mana isi blok dan mana yang berada di luar blok.

Perhatikan dua kode berikut.

Bentuk yang salah:

user_age = 20
if user_age >= 18:
print("Sudah dewasa")
print("Boleh mengakses fitur dewasa")
print("Terima kasih")

Baris print("Sudah dewasa") tidak menjorok, sehingga Python menganggap blok if belum memiliki isi dan menghentikan program dengan pesan IndentationError.

Bentuk yang benar:

user_age = 20
if user_age >= 18:
    print("Sudah dewasa")
    print("Boleh mengakses fitur dewasa")
print("Terima kasih")

Hasil:

Sudah dewasa
Boleh mengakses fitur dewasa
Terima kasih

Kedua baris pertama berada di dalam blok if, sedangkan baris terakhir berada di luar blok sehingga selalu berjalan.

Aturan praktis untuk indentasi Python:

  • gunakan empat spasi untuk satu tingkat indentasi;
  • jangan memakai tab, karena pencampuran tab dan spasi memicu TabError;
  • baris yang menjorok harus selalu diikuti baris sebelumnya yang diakhiri titik dua.

17. Menambahkan else

Blok else berjalan ketika semua kondisi sebelumnya bernilai salah. Bagian ini bersifat opsional dan hanya boleh satu.

user_age = 15
if user_age >= 18:
    print("Sudah dewasa")
else:
    print("Belum dewasa")

Hasil:

Belum dewasa

Tata letak else selalu sejajar dengan if, bukan menjorok ke dalam bloknya.

if kondisi:
    blok_if
else:              # sejajar dengan if
    blok_else

Tanpa else, program tetap berjalan, tetapi tidak melakukan apa pun ketika kondisi salah.

18. Menambahkan elif

Ketika terdapat lebih dari dua kemungkinan, elif dipakai untuk menambahkan kondisi tambahan. elif adalah ringkasan dari else if dan dipakai untuk menghindari indentasi yang terlalu dalam.

score = 75
if score >= 90:
    print("Nilai A")
elif score >= 80:
    print("Nilai B")
elif score >= 60:
    print("Nilai C")
else:
    print("Nilai D")

Hasil:

Nilai C

Python memeriksa kondisi dari atas ke bawah. Dimulai dari score >= 90, nilainya salah, lalu score >= 80 juga salah, kemudian score >= 60 bernilai benar. Satu blok berjalan, yaitu print("Nilai C").

19. Hanya satu blok yang berjalan

Dirantai if, elif, else bersifat berurutan dan saling meniadakan. Begitu satu kondisi bernilai benar, Python berhenti memeriksa kondisi berikutnya.

score = 95
if score >= 90:
    print("Nilai A")
elif score >= 80:
    print("Nilai B")
elif score >= 60:
    print("Nilai C")
else:
    print("Nilai D")

Hasil:

Nilai A

Hanya Nilai A yang muncul. Kondisi score >= 80 memang juga bernilai benar, tetapi tidak diperiksa karena kondisi pertama sudah terpenuhi.

Urutan pemeriksaan penting. Jika kondisi yang paling umum diletakkan paling atas, kondisi yang lebih khusus tidak akan pernah diperiksa.

score = 95

# penulisan ini salah
if score >= 60:
    print("Lulus")
elif score >= 90:
    print("Nilai A")

Hasil:

Lulus

Program berhenti pada kondisi pertama sehingga Nilai A tidak pernah muncul. Kondisi yang paling khusus harus diletakkan paling atas.

Urutan aturan. Dalam rantai if, elif, else, pemeriksaan selalu berjalan dari atas ke bawah dan berhenti pada kondisi pertama yang bernilai benar.

Operator not membalik nilai kebenaran sebuah kondisi.

print(not True)
print(not False)

True

Contoh penerapan:

24. Perbandingan bertingkat

Python dapat menggabungkan beberapa perbandingan dalam satu baris dengan bentuk awal < nilai < akhir.

score = 75
print(0 <= score <= 100)

Hasil:

True

Bentuk tersebut setara dengan menuliskan dua perbandingan sekaligus.

print(0 <= score and score <= 100)

Hasil tetap True. Penulisan bertingkat lebih mudah dibaca.

score = 120
print(0 <= score <= 100)

Hasil:

False

Kesalahan yang perlu dihindari adalah menaruh tanda perbandingan di posisi yang salah.

score = 75
print(0 <= score and <= 100)

Baris tersebut ditolak sebagai kesalahan sintaks karena tanda <= tidak memiliki nilai di sebelah kirinya.

Bentuk yang benar tetap memisahkan kedua batas secara lengkap.

score = 75
print(0 <= score and score <= 100)

Hasil:

True

25. Pemeriksaan None memakai is

None menandakan bahwa tidak ada nilai. Untuk memeriksa None, operator is dipakai, bukan ==.

result = None
if result is None:
    print("Belum ada hasil")

Hasil:

Belum ada hasil

Operator is memeriksa apakah dua nilai menunjuk objek yang sama, bukan apakah nilainya sama. Untuk builtin sederhana seperti None, True, dan False, bentuk ini selalu berlaku.

Aturan praktis. Gunakan == untuk membandingkan nilai, dan is hanya untuk memeriksa apakah suatu nilai adalah None.

29. Kesalahan umum

Bagian ini merangkum kesalahan yang paling sering muncul saat menulis percabangan.

29.1 Lupa titik dua

score = 80
if score >= 60
    print("Lulus")

Program berhenti dengan kesalahan sintaks karena tanda titik dua setelah kondisi tidak ditulis.

29.2 Salah indentasi

score = 80
if score >= 60:
print("Lulus")

Program berhenti dengan IndentationError karena blok if tidak menjorok.

29.3 Mencampur tab dan spasi

score = 80
if score >= 60:
    print("Lulus")
	print("Baris lain")

Program berhenti dengan TabError. Gunakan spasi secara konsisten, empat spasi untuk satu tingkat.

29.4 Lupa konversi input()

score = input("Nilai: ")
if score >= 60:
    print("Lulus")

Program berhenti dengan kesalahan tipe karena score berupa string. Tambahkan int() atau float().

score = 80
else:
    print("Belum lulus")
if score >= 60:
    print("Lulus")

Program berhenti dengan kesalahan sintaks karena else harus selalu mengikuti blok if.

30. Latihan

Kerjakan latihan berikut tanpa melihat contoh sebelumnya lebih dahulu.

  1. Tulis program yang meminta dua angka, kemudian menampilkan pesan lebih besar, sama, atau lebih kecil.
  2. Tulis program yang memeriksa apakah sebuah angka genap atau ganjil.
  3. Tulis program yang meminta tahun lahir, lalu menampilkan kelompok umur.
  4. Tulis program yang memeriksa apakah tiga sisi yang dimasukkan dapat membentuk segitiga.
  5. Tulis program yang menampilkan nilai huruf dari 0 sampai 100 beserta keterangan kelulusannya.

Kunci jawaban singkat.

# 1. Perbandingan tiga nilai
first_number = float(input("Angka pertama: "))
second_number = float(input("Angka kedua: "))

if first_number > second_number:
    print("lebih besar")
elif first_number == second_number:
    print("sama")
else:
    print("lebih kecil")
# 2. Genap atau ganjil
number = int(input("Masukkan angka: "))

if number % 2 == 0:
    print("Genap")
else:
    print("Ganjil")
# 4. Syarat segitiga
side_a = float(input("Sisi a: "))
side_b = float(input("Sisi b: "))
side_c = float(input("Sisi c: "))

if side_a + side_b > side_c and side_b + side_c > side_a and side_a + side_c > side_b:
    print("Dapat membentuk segitiga")
else:
    print("Tidak dapat membentuk segitiga")

31. Program lengkap: penentuan nilai

Program berikut menggabungkan masukan pengguna, rantai kondisi, dan operator logika.

name = input("Nama     : ")
score = int(input("Nilai    : "))
attendance = int(input("Kehadiran: "))

if score >= 60 and attendance >= 75:
    grade = "A"
elif score >= 60:
    grade = "B"
elif score >= 50:
    grade = "C"
else:
    grade = "D"

print()
print("=== HASIL ===")
print(f"Nama      : {name}")
print(f"Nilai     : {score}")
print(f"Kehadiran : {attendance}%")
print(f"Nilai huruf: {grade}")

Contoh interaksi:

Nama     : Rian
Nilai    : 78
Kehadiran: 80

=== HASIL ===
Nama      : Rian
Nilai     : 78
Kehadiran : 80%
Nilai huruf: B

Alur program pada contoh tersebut:

  1. program membaca nama, nilai, dan kehadiran;
  2. kondisi pertama diperiksa: nilai 78 lebih dari 60, tetapi kehadiran 80 di bawah 75, sehingga syarat tidak lengkap;
  3. kondisi kedua diperiksa: nilai 78 lebih dari 60, sehingga nilai huruf B dipilih;
  4. hasil ditampilkan dengan f-string.
