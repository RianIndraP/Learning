Bab 3: Input, Output, dan Interaksi dengan Pengguna

Pada bab sebelumnya, program hanya menampilkan nilai yang ditulis langsung di dalam kode. Bab ini membahas cara program menerima masukan dari pengguna, mengolahnya, lalu menampilkan hasilnya kembali melalui input() dan print().

Banyak cara untuk menuju satu tujuan

Catatan versi. Catatan ini mengacu pada Python 3.14.x. Nama fungsi, pesan kesalahan, dan hasil print() pada versi yang lebih baru dapat sedikit berbeda.

1. Apa itu input dan output?

Dalam pemrograman, interaksi program dengan pengguna umumnya terdiri atas input dan output.

INPUT          PROSES              OUTPUT
data masuk  →  olah data  →  hasil ditampilkan
BagianIsi
InputData yang diberikan ke program, misalnya nama, umur, harga, atau pilihan menu.
ProsesPengolahan input menggunakan variabel, operator, dan logika.
OutputHasil yang ditampilkan program, misalnya sapaan, perhitungan, atau laporan.

Misalnya, kalkulator menerima angka 10 dan 5 sebagai input. Program menjumlahkan keduanya, lalu menampilkan 15 sebagai output.

Alur umum dalam Python dapat digambarkan sebagai berikut.

Pengguna memasukkan angka
          ↓
Program menerima input
          ↓
Python menghitung
          ↓
Program menampilkan hasil

Python menyediakan dua fungsi bawaan yang paling dasar untuk kebutuhan ini.

FungsiKegunaan
input()Menerima masukan dari pengguna.
print()Menampilkan informasi atau hasil.

Keduanya merupakan fungsi bawaan, sehingga tidak perlu memasang library tambahan untuk menggunakannya.

2. Output dengan print()

print() adalah fungsi bawaan Python yang digunakan untuk mengeluarkan informasi ke suatu output, yang secara default berupa terminal atau konsol.

2.1 Contoh paling sederhana

print("Halo, dunia!")

Hasil:

Halo, dunia!

Pada pemanggilan ini, print adalah nama fungsi, tanda kurung () menyediakan argumen, dan "Halo, dunia!" adalah string yang ingin ditampilkan. Tanda kutip tidak ikut ditampilkan.

2.2 Menampilkan nilai variabel

nama = "Rian"
umur = 18
print(nama)
print(umur)

Hasil:

Rian
18

Perhatikan beda antara dua pemanggilan berikut.

nama = "Rian"
print(nama)
print("nama")

Hasil:

Rian
nama

Pada print(nama), Python membaca variabel nama lalu menampilkan isinya. Pada print("nama"), Python hanya menampilkan teks literal nama.

2.3 Menampilkan beberapa nilai sekaligus

nama = "Rian"
umur = 18
kota = "Banda Aceh"
print(nama, umur, kota)

Hasil:

Rian 18 Banda Aceh

Secara default, print() memberikan satu spasi pada jarak antar argumen dan menambahkan baris baru setelah output selesai. Kedua perilaku ini dapat diubah menggunakan parameter sep dan end.

2.4 Menampilkan informasi yang terstruktur

nama = "Rian"
umur = 18
kota = "Banda Aceh"

print("Nama:", nama)
print("Umur:", umur)
print("Kota:", kota)

Hasil:

Nama: Rian
Umur: 18
Kota: Banda Aceh

Pola ini berguna untuk menampilkan informasi yang terdiri dari label dan nilainya.

3. f-string untuk output dinamis

f-string adalah cara praktis untuk memasukkan nilai variabel atau ekspresi Python ke dalam string. Pada f-string, huruf f diletakkan sebelum tanda kutip, sedangkan nilai yang ingin dimasukkan ditulis di dalam kurung kurawal.

nama = "Rian"
umur = 18
print(f"Halo, nama saya {nama}.")
print(f"Saya berumur {umur} tahun.")

Hasil:

Halo, nama saya Rian.
Saya berumur 18 tahun.

Tiga hal penting pada f-string:

  • tanda f ditulis sebelum tanda kutip;
  • {nama} menentukan tempat nilai variabel dimasukkan;
  • Python mengonversi nilai variabel ke representasi teks secara otomatis.

3.1 f-string untuk laporan

nama_barang = "Keyboard"
harga = 150000
jumlah = 2
total = harga * jumlah

print(f"Barang: {nama_barang}")
print(f"Harga satuan: Rp{harga}")
print(f"Jumlah: {jumlah}")
print(f"Total pembayaran: Rp{total}")

Hasil:

Barang: Keyboard
Harga satuan: Rp150000
Jumlah: 2
Total pembayaran: Rp300000

3.2 f-string dengan ekspresi

a = 10
b = 5
print(f"Hasil penjumlahan: {a + b}")

Hasil:

Hasil penjumlahan: 15

4. Input dengan input()

Fungsi input() adalah fungsi bawaan Python untuk menerima masukan dari pengguna, biasanya melalui keyboard.

4.1 Dengan dan tanpa input

Tanpa input(), nilai harus ditentukan langsung di kode:

nama = "Rian"
print(f"Halo, {nama}!")

Program ini selalu menggunakan nama Rian kecuali kode diubah.

Dengan input(), program dapat menerima berbagai nama tanpa menyunting kode setiap kali dijalankan:

nama = input("Masukkan nama: ")
print(f"Halo, {nama}!")

Ketika dijalankan, program menampilkan:

Masukkan nama:

Pengguna lalu mengetik:

Rian

Setelah Enter ditekan, hasilnya:

Halo, Rian!

Jika masukan berbeda, misalnya Andi, hasil program juga berubah.

4.2 Membongkar baris input

nama = input("Masukkan nama: ")

Beberapa bagian dari baris tersebut memiliki fungsi berikut.

Bagian kodeFungsi
namaVariabel untuk menyimpan data yang diterima.
=Menyimpan hasil ke variabel.
input()Meminta dan menerima masukan pengguna.
"Masukkan nama: "Pesan yang ditampilkan sebelum pengguna mengetik.

Urutan kejadiannya:

input("Masukkan nama: ")
              ↓
Pesan ditampilkan
              ↓
Pengguna mengetik Rian
              ↓
Pengguna menekan Enter
              ↓
input() menghasilkan string "Rian"
              ↓
Variabel nama menyimpan nilai itu

4.3 input() tanpa disimpan

input() menghasilkan nilai. Jika hasilnya tidak disimpan ke variabel, masukan itu tidak tersedia lagi.

input("Masukkan nama: ")

Praktik yang umum adalah menyimpannya:

nama = input("Masukkan nama: ")

Gunakan nilai itu berulang kali selama masih dalam cakupan program.

5. Hasil input() selalu string

Secara normal, input() menghasilkan nilai bertipe str, sekalipun pengguna mengetik angka.

umur = input("Masukkan umur: ")
print(umur)
print(type(umur))

Misalnya pengguna mengetik 18, outputnya:

18

Mengapa tipenya str? Karena Python membaca masukan sebagai teks. Python tidak otomatis menyimpulkan bahwa teks 18 harus menjadi integer. Dengan kata lain:

"18" → string

5.1 Masalah ketika menghitung input angka

Misalnya program menanyakan umur lalu menambah 1:

umur = input("Masukkan umur: ")
hasil = umur + 1
print(hasil)

Jika pengguna memasukkan 18, program memunculkan TypeError karena tidak bisa menjumlahkan string dengan integer pada baris hasil = umur + 1.

Makna singkatnya: variabel umur bertipe string, sedangkan 1 bertipe integer, sedangkan operator + membutuhkan tipe yang saling mendukung.

5.2 Solusi: konversi tipe data

Gunakan int() untuk mengonversi teks angka menjadi integer.

umur = int(input("Masukkan umur: "))
hasil = umur + 1
print(hasil)

Jika pengguna memasukkan 18, hasilnya:

Masukkan umur: 18
19

Urutan kejadian:

  1. input() menerima jawaban sebagai string.
  2. int() mengonversi string itu menjadi integer jika isinya valid.
  3. Hasil konversi disimpan di variabel umur.

Secara sederhana:

"18"    → string
  ↓ int()
18      → integer
  ↓ + 1
19      → integer

6. Mengubah input menjadi tipe data yang sesuai

6.1 Input angka bulat dengan int()

Gunakan int() untuk bilangan bulat.

umur = int(input("Masukkan umur: "))
jumlah_barang = int(input("Jumlah barang: "))
print(f"Umur: {umur}")
print(f"Jumlah barang: {jumlah_barang}")

6.2 Input angka desimal dengan float()

Untuk bilangan desimal, gunakan float().

tinggi = float(input("Masukkan tinggi badan dalam cm: "))
print(f"Tinggi badan: {tinggi} cm")

Pemisah desimal yang umum digunakan dalam Python adalah titik, sehingga masukan ditulis 170.5, bukan 170,5.

6.3 Input teks dengan str()

input() sudah menghasilkan string, sehingga konversi dengan str() biasanya tidak diperlukan.

nama = input("Masukkan nama: ")

6.4 Tentang bool()

Python memiliki fungsi bool(), tetapi penggunaannya untuk mengubah input teks menjadi jawaban ya atau tidak dapat membingungkan pemula.

jawaban = input("Status mahasiswa (ya/tidak): ")
status = bool(jawaban)
print(status)

Jika pengguna mengetik tidak, hasilnya tetap True, karena string yang tidak kosong dianggap benar oleh bool().

Untuk saat ini, simpan jawaban pengguna sebagai string:

jawaban = input("Status mahasiswa (ya/tidak): ")
print(jawaban)

7. Menerima banyak input dalam satu program

nama = input("Nama: ")
umur = int(input("Umur: "))
kota = input("Asal kota: ")

print("\n=== DATA PENGGUNA ===")
print(f"Nama : {nama}")
print(f"Umur : {umur} tahun")
print(f"Kota : {kota}")

Contoh interaksi:

Nama: Rian
Umur: 18
Asal kota: Banda Aceh

=== DATA PENGGUNA ===
Nama : Rian
Umur : 18 tahun
Kota : Banda Aceh

Python mengeksekusi instruksi secara berurutan dari atas ke bawah, kecuali ada struktur program lain yang mengubah alurnya.

8. Parameter sep pada print()

Secara default, ketika beberapa nilai ditampilkan sekaligus, print() memisahkannya dengan spasi.

Parameter sep menentukan string pemisah antarnilai.

print("Python", "Java", "C++", sep=" | ")
print(1, 2, 3, sep="-")
print("A", "B", "C", sep=", ")

Hasil:

Python | Java | C++
1-2-3
A, B, C

Python menempatkan nilai sep di antara argumen yang ditampilkan. Argumen sep harus berupa string.

9. Parameter end pada print()

Secara default, setiap pemanggilan print() mengakhiri output dengan karakter baris baru.

print("Halo")
print("Rian")

Hasil:

Halo
Rian

Parameter end mengubah perilaku tersebut.

print("Halo", end=" ")
print("Rian")

Hasil:

Halo Rian

10. Catatan penting

Ada beberapa hal yang perlu diingat dari bab ini.

  • print() menampilkan output, secara default ke terminal atau konsol.
  • input() selalu menghasilkan nilai bertipe str.
  • Untuk menghitung nilai yang dimasukkan pengguna, konversi dulu dengan int() atau float().
  • Parameter sep mengatur pemisah antarnilai, sedangkan end mengatur karakter di akhir output.
  • f-string menggabungkan teks dan nilai variabel di dalam satu kalimat dengan lebih ringkas.
