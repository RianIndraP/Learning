# Soal Praktikum 32

Buat sebuah program yang meminta data seorang mahasiswa:

1. Nama, yang disimpan dalam variabel bernama `nama_lengkap`, dan
2. NPM, yang disimpan dalam variabel bernama `npm`

Menghasilkan pesan seperti tampilan berikut:

```text
Nama lengkap: Rahmad Dawood
NPM anda: 123456789

Selamat datang Rahmad Dawood ( 123456789 ) di matakuliah Pemrograman 1.
```
